# Calibrated Failure Probabilities for Frozen CPU Optical Flow

The first confidence estimate for an optical-flow match is often decisive. This task focuses on the cases where it is uncertain. The Judge fixes that subset from two image-derived signals, then asks whether a compact model can use local visual evidence to give better probabilities on new scenes. All estimators run on CPU and share the same motion vectors.

| Research Question | Files/components the agent may modify | Work-side fitting, diagnostics, and a JSON list of ≤16 axis-aligned additive trees (≤128 internal nodes overall) with finite thresholds and finite leaf logits. The runner returns the frozen reference directly for an empty tree list. Outside the cohort it returns the original two-cue probability. |

| Reference Baseline | Baseline implementation or artifact | The reference uses two released numeric artifacts. [model.json](model.json) contains the original 9×7 table of Work failure frequencies using forward/backward cycle discrepancy and brightness residual with shrinkage. Its entry p0 fixes the cohort. Within the cohort, take the largest of the four L1 flow disagreements to axial neighbors, then bin it at [0.5, 1, 2, 4, 8, 16] px using NumPy digitize (equal values enter the upper bin). Solution emits the empty tree list without fitting. The two-cue table and constant 0.5 serve as controls. |

| Evaluation | Evaluation mode and input | Judge generates fixed forward and backward DIS FAST flows from two native grayscale frames. Query the grid anchored at (0,0) with stride 4 on each axis. Among pixels valid under the official mask, include exactly those with 0.25 ≤ p0 ≤ 0.75, where p0 comes from the frozen two-cue table before applying any offset. The eligibility inputs exclude the ground truth and all candidate predictions. The event is Euclidean endpoint error strictly greater than 3 px. Judge looks up the ground truth only for scoring. Reverse-flow sampling is bilinear; out-of-frame cycle discrepancy maps to the last table bin. This conditional population is meaningful wherever the initial confidence is too close to 0.5 to support a confident decision. |
| Evaluation | Reward or score definition | In each scene, sum (p−y)² over its fixed cohort and divide by its total number of cohort samples pooled across frames. Average scene losses with equal scene weight. Reward = frozen three-cue scene-macro Brier minus candidate scene-macro Brier. Zero reproduces the reference. Conditional Brier is a proper probability score because eligibility is fixed before candidate predictions and independent of the observed label. A frame with zero eligible samples contributes zero count; a scene with zero eligible samples stops provisioning without a score, with no replacement or change of denominator. Final success requires lower Brier in both fixed final scenes. |

| Evaluation | Noise handling and meaningful improvement | Fixed data and pinned CPU build give deterministic predictions. Report paired losses and cohort counts per final scene.
