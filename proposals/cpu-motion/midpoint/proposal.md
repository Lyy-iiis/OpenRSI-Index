# Visibility-Weighted Midpoint Synthesis with Frozen CPU Motion Fields

When two video frames are separated by a missing frame, the two endpoints can project different appearances to the same midpoint. This task asks an agent to decide which projected intensity to trust, under fixed bidirectional CPU motion estimates. The answer is scored against the actual withheld image.

| Reference Baseline | Baseline implementation or artifact | Reference JSON selects the released cycle-weighted mode. Each source pixel projects by 0.5 times its endpoint DIS FAST vector, distributes to the four adjacent pixels bilinearly and votes with importance 1/(1+min(forward/backward discrepancy,16)). Both directions contribute before normalization. Out-of-bounds deposits are discarded; mass ≤1e−8 uses the colocated endpoint average. Solution writes the mode name without fitting. A cross-dissolve and equal-weight splat are controls. Normalized forward splatting follows the operator family described by [Niklaus and Liu](https://github.com/sniklaus/softmax-splatting); this self-contained CPU implementation uses OpenCV DIS and no learned checkpoint. |

| Reference Baseline | Baseline metric reported by the repository | OpenCV provides the motion estimator; the pilot supplies midpoint reconstruction measurements. On 20 triplets from five pilot scenes, scene-mean squared error was **297.8677** for a cross-dissolve, **135.5366** for equal splatting and **134.9456** for cycle weighting. | Evaluation | Evaluation mode and input | Direct rendering from the first and last frames of a native-resolution three-frame Final clip, converted to grayscale by OpenCV. Supply just these endpoints to the predictor. Judge computes both DIS fields, renders the middle image in floating point from the submitted weights, and compares every output pixel, including collision and hole pixels, with the actual intervening 8-bit frame. |
| Evaluation | Reward or score definition | Within each scene, average squared grayscale intensity difference across all pixels and triplets. Then average scene means equally. Reward = (reference MSE − candidate MSE)/reference MSE. Positive is better; zero reproduces the reference. Report PSNR from the macro MSE as a secondary metric. Final success requires lower macro MSE and lower MSE in both final scenes. |
