# Calibrated Failure Probabilities for Frozen CPU Optical Flow

The first confidence estimate for an optical-flow match is often decisive. This task focuses on the cases where it is uncertain. The Judge fixes that subset from two image-derived signals, then asks whether a compact model can use local visual evidence to give better probabilities on new scenes, especially where confident errors would mislead a downstream consumer. All estimators run on CPU and share the same motion vectors.

| Evaluation | Evaluation mode and input | Judge generates fixed forward and backward DIS FAST flows from two native grayscale frames. Query the grid anchored at (0,0) with stride 4 on each axis. Among pixels valid under the official mask, include exactly those with 0.25 ≤ p0 ≤ 0.75, where p0 comes from the frozen two-cue table before applying any offset. The eligibility inputs exclude the ground truth and all candidate predictions. The event is Euclidean endpoint error strictly greater than 3 px. Judge looks up the ground truth only for scoring. Reverse-flow sampling is bilinear; out-of-frame cycle discrepancy maps to the last table bin. This conditional population is meaningful wherever the initial confidence is too close to 0.5 to support a confident decision. |
| Evaluation | Reward or score definition | Primary loss is the mean binary negative log likelihood in natural-log units. At each eligible sample let z be the finite natural-log odds from the frozen reference plus the candidate correction, y=1 for an endpoint error >3 px and y=0 otherwise. Score softplus(−z) for y=1, softplus(z) for y=0, using logaddexp for numerical stability without probability clipping. Pool the loss over eligible samples within a scene, then average scene means equally. This strictly proper score has infimum zero and no fixed upper bound. Reward = frozen three-cue log loss minus candidate log loss in nats per eligible sample. Positive is better and zero reproduces the baseline. A frame with no eligible samples adds zero count. A formal scene with zero eligible samples stops provisioning without a score or replacement. Final success requires lower primary loss in both final scenes. Report Brier and reliability bins as secondary diagnostics. |
