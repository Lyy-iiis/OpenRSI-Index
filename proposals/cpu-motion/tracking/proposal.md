# When to Re-anchor a Sparse CPU Point Track

In a short video, matching each new frame to the previous one accumulates drift, while matching back to the first frame can fail when appearance changes. This task asks an agent to choose the temporal reference for each point, using only evidence available at that time.

| Research Question | Scientific question | Can a causal reference-selection policy reduce five-transition endpoint drift for fixed interest points, compared with choosing the valid LK hypothesis with the lower patch cost, when all methods receive the same two LK proposals per step? |
| Research Question | Why this is scientific research rather than pure engineering optimization | First-frame anchoring preserves identity but can be misleading after rotation or illumination change. Incremental matching adapts appearance but propagates previous errors. Experiments can test disagreement, time since anchoring, motion history and persistence of cost asymmetry. A choice changes the next incremental hypothesis, so independent per-frame classification cannot capture the full effect. The output is a point trajectory with fixed query identities. |

| Evaluation | Fixed evaluation protocol | Fixed inventory: **10 Work, 10 public pilot, 90 validation, 90 final six-frame clips**. Work families: alley_1, ambush_5, bamboo_1, market_2, shaman_2. Unused-for-fitting public pilot: bandage_1, cave_2, mountain_1, sleeping_2, temple_2. Validation: all listed windows in bandage_2 and cave_4. Final: all listed windows in sleeping_1 and temple_3. Pilot sibling sequences exist, and no formal validation/test scores are claimed. | Evaluation | Evaluation mode and input | At frame zero use OpenCV goodFeaturesToTrack(maxCorners=500, qualityLevel=.01, minDistance=7, blockSize=7). At each of five transitions run adjacent LK, then first-frame-to-current LK seeded by the adjacent result or last position. LK window 15×15, maxLevel=2, 10 iterations, epsilon=.03. Validity requires success, finite coordinates and image bounds. Ground truth is composed along the true path by bilinear sampling of successive flows; for every step all four donors must be valid, unoccluded, with componentwise flow range ≤3 px, and the next point must remain in frame. Use only queries that remain eligible through the scored step. Eligibility is independent of candidate state. |
| Evaluation | Reward or score definition | At step 5, valid predictions contribute min(Euclidean position error,20 px); lost predictions on eligible targets contribute 20 px. Pool the sum over eligible queries within each scene, then average scene means. Reward = reference loss − candidate loss (px), higher is better. Report steps 1–4 and lost-query fraction as diagnostics. A clip with zero eligible targets contributes zero count; a whole scene with zero eligible targets is a data-qualification failure before research. Final success requires lower macro loss and lower loss on both final scenes. |
| Evaluation | Feedback visible to the agent | Validation macro loss, aggregate loss by step and fraction of eligible targets lost. Work exposes labeled clips and allows paired trajectory inspection. |
| Evaluation | Evaluation information hidden from the agent | At inference, only current/past images and per-query state are usable. Judge flows, composed tracks, visibility labels, individual predictions and final test results are excluded from Work. |
| Evaluation | Measures preventing reward hacking | The Judge constructs queries and targets independently of candidate choices. A policy consumes only causal features, has no filesystem or network capability, and cannot choose which targets are counted. Loss caps and lost-track penalties are enforced for every eligible final query. |
| Evaluation | Noise handling and meaningful improvement | Reuse identical first-frame queries, OpenCV build, loss cap and ground-truth eligibility for all policies. Quantify paired scene changes and counts; adjacent clips and queries are correlated. Composition approximates physical tracks, and the four-donor agreement filter deliberately restricts claims to visible, locally consistent surfaces. |
